ОТВЕТЫ НА КОНТРОЛЬНЫЕ ВОПРОСЫ (Практическая работа №3)

1. Что такое интерфейс в PHP? Чем интерфейс отличается от абстрактного класса — приведите не менее трёх различий.
Интерфейс в PHP — это «контракт», который описывает, какие методы должен реализовать класс, но не содержит их логики (реализации). 
Три отличия от абстрактного класса:
- Интерфейс не может содержать свойств (полей) класса, только константы. Абстрактный класс может иметь обычные и статические свойства.
- Все методы в интерфейсе по умолчанию являются публичными и абстрактными (не имеют тела). Абстрактный класс может содержать как абстрактные методы, так и методы с полной реализацией.
- Класс может реализовывать (implements) неограниченное количество интерфейсов, но может наследовать (extends) только один абстрактный класс (ограничение одиночного наследования).

2. Может ли один класс реализовывать несколько интерфейсов? Как это записывается? Может ли класс одновременно наследовать класс и реализовывать интерфейсы?
Да, класс может реализовывать несколько интерфейсов. Они перечисляются через запятую после ключевого слова implements (например: `class MyClass implements InterfaceA, InterfaceB`). 
Да, класс может одновременно наследовать один родительский класс и реализовывать несколько интерфейсов. В этом случае сначала указывается ключевое слово extends с именем родительского класса, а затем implements со списком интерфейсов: `class MyClass extends ParentClass implements InterfaceA, InterfaceB`.

3. Что такое трейт и какую проблему он решает? Чем трейт отличается от класса и от интерфейса?
Трейт (trait) — это механизм горизонтального повторного использования кода в PHP. Он решает проблему одиночного наследования, позволяя «встраивать» наборы методов и свойств в разные, не связанные между собой иерархией классы.
Отличия:
- От класса: трейт нельзя инстанциировать (создать его объект через `new`), он существует только для того, чтобы быть подключенным внутрь класса через `use`.
- От интерфейса: трейт содержит реальную реализацию методов и может иметь свойства, тогда как интерфейс описывает только сигнатуры методов (контракт) без их реализации.

4. Как разрешить конфликт, если два трейта содержат метод с одинаковым именем? Напишите пример с insteadof и as.
Если два подключенных трейта имеют методы с одинаковыми именами, PHP выдаст фатальную ошибку. Конфликт разрешается внутри блока фигурных скобок при подключении трейтов. Оператор `insteadof` указывает, какой именно метод использовать, а оператор `as` создает псевдоним (алиас) для второго метода, чтобы он остался доступен.
Пример:
trait A { public function hello() { return "A"; } }
trait B { public function hello() { return "B"; } }
class Test {
    use A, B {
        A::hello insteadof B; // Используем метод из трейта A
        B::hello as helloB;   // Метод из трейта B доступен как helloB()
    }
}

5. Могут ли трейты содержать абстрактные методы? Может ли трейт использовать другой трейт? Приведите пример из задания 4.
Да, трейты могут содержать абстрактные методы. Это заставляет класс, который использует этот трейт, обязательно реализовать данный метод. 
Да, трейт может использовать другой трейт (композиция трейтов). Это позволяет собирать сложную логику из более мелких переиспользуемых частей. 
Пример из задания 4: трейт `CrudOperations` использует внутри себя трейт `LoggableTrait` с помощью конструкции `use LoggableTrait;`. Благодаря этому класс `Product`, подключивший `CrudOperations`, автоматически получает доступ к методам `log()` и `printLogs()`, не подключая `LoggableTrait` напрямую.
