ОТВЕТЫ НА КОНТРОЛЬНЫЕ ВОПРОСЫ (Практическая работа №1)

1. Что такое конструктор и деструктор? В какие моменты времени они вызываются интерпретатором PHP?
Конструктор (__construct) — это специальный метод, который автоматически выполняется в момент создания объекта с помощью оператора new. Его главная задача — инициализация свойств объекта начальными значениями и подготовка его к работе. Деструктор (__destruct) — это метод, который вызывается автоматически, когда объект удаляется из памяти. Это происходит либо при явном вызове функции unset() для переменной-объекта, либо автоматически в конце выполнения скрипта, когда PHP очищает все ресурсы.

2. Может ли класс работать без явно объявленного конструктора? Что произойдёт при вызове new ClassName() с аргументами, если конструктор не объявлен?
Да, класс может работать без явно объявленного конструктора. В этом случае PHP использует неявный (дефолтный) пустой конструктор, который просто создаёт объект без инициализации свойств. Однако, если при вызове new ClassName() передать аргументы (например, new ClassName("Иван")), а конструктор не объявлен или объявлен без параметров, интерпретатор PHP выдаст фатальную ошибку (Fatal error): "Too many arguments to function", так как дефолтный конструктор не ожидает никаких параметров.

3. Как передать параметры конструктору дочернего класса в родительский конструктор? Напишите пример.
Для этого внутри конструктора дочернего класса необходимо явно вызвать конструктор родительского класса с помощью ключевого слова parent:: и оператора разрешения области видимости ::, передав ему соответствующие аргументы.
Пример:
class Child extends ParentClass {
    public function __construct(string $name, int $age, string $school) {
        parent::__construct($name, $age); // Передаём имя и возраст родителю
        $this->school = $school;          // Инициализируем своё свойство
    }
}

4. Что произойдёт, если в дочернем классе объявить конструктор и не вызвать parent::__construct()?
Если в дочернем классе переопределён конструктор, PHP не вызывает конструктор родительского класса автоматически. Если программист забудет написать parent::__construct(), то код инициализации родителя не выполнится. Это приведёт к тому, что свойства, которые должны были быть заданы в родительском классе, останутся неинициализированными (или примут значения по умолчанию), что может вызвать ошибки при попытке использовать методы родительского класса, зависящие от этих свойств.

5. Когда деструкторы вызываются при завершении скрипта и в каком порядке уничтожаются объекты? Продемонстрируйте порядок вызова на примере двух объектов.
При завершении скрипта PHP автоматически уничтожает все оставшиеся в памяти объекты. Порядок вызова деструкторов, как правило, обратен порядку создания объектов (принцип LIFO: Last In, First Out), либо зависит от порядка разрешения циклических ссылок сборщиком мусора. 
Пример:
$obj1 = new MyClass("A"); // Создан первым
$obj2 = new MyClass("B"); // Создан вторым
// Конец скрипта:
// 1. Сработает деструктор для $obj2 ("B")
// 2. Сработает деструктор для $obj1 ("A")
