 Ответы на контрольные вопросы

1. Зачем добавлять папку PHP в переменную PATH и как проверить, что PHP установлен? 
   Добавление в PATH позволяет запускать команду `php` из любой папки в CMD, не указывая полный путь к `php.exe`. Проверить установку можно командой `php -v`.

2. Какой командой запускается встроенный сервер PHP и как указать другой порт или корневую папку?  
   Запуск: `php -S localhost:8000`. Другой порт: `php -S localhost:8080`. Другая корневая папка: `php -S localhost:8000 -t C:\путь\к\папке`.

3. Почему форма загрузки не работает без `enctype="multipart/form-data"`?  
   Без этого атрибута браузер отправляет данные формы как обычный текст, и PHP не сможет распознать файл. Массив `$_FILES` останется пустым.

4. Какие ключи содержит массив `$_FILES['userfile']` и что хранится в `tmp_name`? 
   Ключи: `name`, `full_path`, `type`, `tmp_name`, `error`, `size`. В `tmp_name` хранится временный путь к файлу на сервере, куда PHP сохранил его до перемещения.

5. Чем `move_uploaded_file()` отличается от `copy()`?  
   `move_uploaded_file()` дополнительно проверяет, что файл действительно был загружен через HTTP POST. Это защищает от злоумышленников, пытающихся переместить системные файлы. `copy()` такой проверки не делает.

6. Чем отличаются директивы `upload_max_filesize` и `post_max_size`? Какое значение должно быть больше и почему?  
   `upload_max_filesize` ограничивает размер одного файла, а `post_max_size` ограничивает размер всего POST-запроса (все файлы + текстовые поля). `post_max_size` должен быть больше, иначе запрос будет отброшен целиком.

7. Что произойдёт с массивами `$_POST` и `$_FILES`, если запрос больше `post_max_size`?  
   Оба массива будут полностью пустыми. Скрипт не получит никаких данных от формы.

8. Почему `upload_max_filesize` нельзя изменить через `ini_set()`?  
   Потому что к моменту запуска PHP-скрипта сервер уже принял (или отклонил) файл на основе настроек из `php.ini`. Изменять можно только `memory_limit` и `max_execution_time`.

9. Для чего при удалении и сохранении файлов используется `basename()`? 
   Функция `basename()` отсекает пути к директориям. Это защищает от атак "Directory Traversal", когда злоумышленник пытается передать имя файла вроде `../../index.php`, чтобы удалить или перезаписать важные файлы сайта.

10. Почему нельзя разрешать загрузку файлов с расширением `.php`?  
    Если разрешить загрузку `.php`, злоумышленник может загрузить файл с вредоносным кодом, а затем выполнить его, просто открыв ссылку на этот файл в браузере, что приведет к взлому сервера.
